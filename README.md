# special_Legend｜Phaser 瀏覽器 RPG

使用 **JavaScript 與 Phaser 3** 製作的劇情式瀏覽器 RPG，結合地圖探索、角色對話、劇情分支與存讀檔功能。

## 核心功能
- **劇情互動：** 角色移動、地圖探索、對話與分支選擇。
- **事件觸發：** 地圖觸發器、單次／重複觸發控制及隱藏彩蛋。
- **狀態管理：** 使用 `localStorage` 保存角色位置、劇情進度與遊戲狀態，並處理讀檔後舊對話框殘留問題。
- **操作介面：** 鍵盤與手機觸控操作、遊戲選單及音量設定。

## 技術
JavaScript、Phaser 3、HTML、CSS、localStorage。

## 如何體驗
下載或 Clone 專案，使用本機靜態伺服器（例如 VS Code Live Server）開啟 `index.html`。

```bash
git clone https://github.com/zoey0603/special_Legend.git
```

**基本操作：** 方向鍵移動、Enter／Space 確認、Esc 返回、S 存檔、Q 開啟選單；手機可使用觸控操作。
